🏗️ 1. Vue d'ensemble de l'architecture

📐 Architecture Générale

MCBusiness est une plateforme e-commerce complète construite autour de plusieurs modules interconnectés :

  • Gestion des utilisateurs - Authentification, profils, ambassadeurs
  • Catalogue produits - Produits, variantes, stocks, catégories
  • Système commercial - Commandes, paiements, livraisons
  • Système de parrainage - Commissions, bonus, génération de revenus
  • Administration - Gestion globale, employés, statistiques

🔗 Entités Centrales

Les entités principales qui structurent toute la base de données :

  • ApplicationUser - Utilisateur central (clients, fournisseurs, ambassadeurs)
  • Company - Entreprises fournisseurs
  • Product - Catalogue de produits
  • Order - Commandes et transactions
  • Payment - Gestion des paiements

📝 Résumé Exécutif

🎯 Architecture MCBusiness - Points Clés

La base de données MCBusiness comprend 75+ tables organisées en 12 modules principaux :

👥 Gestion Utilisateurs

ApplicationUser, Wallet, Address, UserActivity

🛍️ Catalogue Produits

Product, ProductVariant, Category, Stock, Brand

📦 Gestion Commandes

Order, OrderProduct, Cart, Shipment

💳 Système Paiement

Payment, Transaction, Currency, Stripe

🤝 Système Parrainage

Referral, AmbassadorPlan, Commission

🏢 Gestion Entreprises

Company, CompanySector, Employee

🔍 Fonctionnalités Avancées

  • Multi-devise : Support de 6 devises (HTG, USD, EUR, CAD, DOP, GBP)
  • Multi-langue : FR, HT, EN, ES, PT
  • RGPD Compliant : Système de cookies granulaire avec consentement
  • MLM 3 niveaux : Système de parrainage sur 3 générations
  • Soft Delete : Suppression logique sur toutes les entités principales
  • Audit Trail : UserActivityLog pour traçabilité complète
  • Notifications : Système de notifications en temps réel
  • Géolocalisation : Support Country → State → City → Neighborhood
